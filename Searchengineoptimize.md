# Search Engine Optimization (SEO) Checklist

## On-Page SEO

### Content Optimization
- [ ] **Keyword Research**: Identify primary and secondary keywords for each page.
- [ ] **Title Tags**: unique, descriptive, and containing primary keywords (under 60 chars).
- [ ] **Meta Descriptions**: compelling summaries including keywords (under 160 chars).
- [ ] **Header Tags (H1, H2, H3)**: Use standard hierarchy. One H1 per page containing the main keyword.
- [ ] **URL Structure**: Clean, descriptive, and using hyphens for separation (e.g., `/product-name`).
- [ ] **Image Alt Text**: Descriptive text for all images for accessibility and SEO.
- [ ] **Internal Linking**: Link relevant product/category pages within content.
- [ ] **Content Quality**: Ensure unique, high-quality, and relevant content (avoid duplicate content).

### Technical SEO
- [ ] **Mobile-Friendliness**: Ensure the site is fully responsive and works well on mobile devices.
- [ ] **Page Speed**: Optimize images, mince CSS/JS, and use caching to improve load times.
- [ ] **HTTPS**: Ensure the site is served over HTTPS.
- [ ] **Sitemap.xml**: Generate and submit a sitemap to Google Search Console.
- [ ] **Robots.txt**: Configure to allow indexing of important pages and block irrelevant ones.
- [ ] **Structured Data (Schema markup)**: Implement Product, Breadcrumb, and Organization schema.
- [ ] **Canonical Tags**: Use canonical tags to prevent duplicate content issues (especially for product variants).
- [ ] **Fix Broken Links**: regular check for 404 errors and existing redirects.

## Off-Page SEO
- [ ] **Backlinks**: Build high-quality backlinks from reputable sites.
- [ ] **Social Signals**: integrate social sharing buttons and maintain active social media profiles.
- [ ] **Google My Business**: (If applicable) specific for local SEO visibility.

## Blog SEO
- [x] **Regular Updates**: Publish consistent, high-quality blog posts related to niche.
- [ ] **Long-tail Keywords**: Target specific queries users might ask.
- [x] **Interlinking**: Link blog posts to product pages to drive conversion.

## User Experience (UX)
- [ ] **Easy Navigation**: rigorous menu structure.
- [ ] **Clear CTA**: Call-to-Action buttons should be visible and persuasive.
- [ ] **Readable Font**: Ensure text is legible on all devices.
